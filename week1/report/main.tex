\subsection{Total Circulation}
For the case of $\alpha=\pi/24$, the calculated total circulation $\Gamma = -1.6408$. For a unit cylinder with unit freestream velocity, we would expect $\Gamma = - 4 \pi \sin \alpha$, which here yields $\Gamma = -1.6402$, agreeing with the panel method result to within \SI{0.1}{\percent}.
